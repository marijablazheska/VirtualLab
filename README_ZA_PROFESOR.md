# VirtualLab Submission Package

Ovoj folder e organiziran spored baranite 5 tocki od zadacata.

## 1. Izvoren kod

Folder: 1_Izvoren_kod/VirtualLabUnity

Sodrzi cist Unity proekt so:
- Assets
- Packages
- ProjectSettings
- README.md

Ne se vkluceni Unity cache folderi kako Library, Logs i UserSettings.

## 2. Izvrshna verzija

Folder: 2_Izvrshna_verzija

Tuka treba da se stavi Android APK ili druga izvrshna verzija. Pogledni IZVRSHNA_VERZIJA_INFO.md.

## 3. Video

Folder: 3_Video

Tuka treba da se stavi video demonstracija. Pogledni UPATSTVO_ZA_VIDEO.md.

## 4. Obrazlozenie

Folder: 4_Obrazlozenie

Sodrzi dokumentacija za aplikacijata, tehnologii, interakcii, upatstvo i referenci.

## 5. Git repozitorium

Ovoj cel folder moze da se koristi kako Git repozitorium. Pogledni 5_Git_repozitorium/GIT_REPO_INFO.md.

## Sto ostanuva da dodades pred isprakjanje

- Android APK vo 2_Izvrshna_verzija
- Video demonstracija vo 3_Video
- Screenshots vo 4_Obrazlozenie/sliki
- GitHub link, ako profesorot bara online repozitorium
