# Izvrshna verzija

Vo ovoj folder treba da se stavi izvrshnata verzija na aplikacijata.

Preporacana izvrshna verzija:
- Android APK za mobilen ured so 3D Box/Cardboard viewer

Predlozen naziv:
VirtualLab_3DBox.apk

Kako da se napravi Android build vo Unity:

1. Otvori go proektot vo Unity 6000.3.17f1.
2. Odberi File > Build Profiles ili File > Build Settings.
3. Izberi Android.
4. Klikni Switch Platform.
5. Vo Player Settings postavi Landscape Left ili Landscape Right.
6. Proveri dali Assets/Scenes/VirtualLab.unity e vo Scenes listata.
7. Klikni Build ili Build And Run.
8. Snimi go APK fajlot vo ovoj folder.

Ako profesorot dozvoluva i PC build, moze dopolnitelno da se dodade Windows build vo podfolder WindowsBuild.
